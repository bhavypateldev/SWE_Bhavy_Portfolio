# Portfolio Website

A clean, minimalist portfolio website built with React, TypeScript, and Vite.


## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run the development server**:
    ```bash
    npm run dev
    ```
## Customization

-   **Content**: Edit `src/components/Hero.tsx` to change the name, bio, and links.
-   **Navigation**: Edit `src/components/Header.tsx` to update menu items.
-   **Styles**: 
    -   Global colors and fonts are in `src/index.css`.
    -   Component-specific styles are in `src/components/*.module.css`.
